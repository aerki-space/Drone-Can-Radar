# Drone-Can-Radar

A compact 24 GHz phased-array radar for small drones, with a native **DroneCAN** interface.

> **Status:** In active development. Hardware design files, firmware and validation results will be
> published as they are completed. Specifications below are design targets and may change.

## Key specifications

| | |
|---|---|
| Frequency | 24 GHz ISM band, FMCW |
| Antenna | 8 × 8 electronically steered phased array |
| Form factor | 50 × 40 mm |
| Beamwidth | ~14° × 17° |
| Field of regard | ±60° azimuth, ±45° elevation |
| Range resolution | 0.75 m |
| Velocity | ±24 m/s |
| Interface | DroneCAN |

## Repository layout

```
docs/
  architecture.md     signal chain, block diagram, power, open decisions
  array-design.md     element, pitch, beam figures, calibration
  link-budget.md      FMCW waveform and radar-equation estimates
  dronecan.md         node behaviour, messages, parameters, ArduPilot integration
  regulatory.md       24 GHz ISM limits that drive the transmit power
dsdl/aerki/radar/     vendor DroneCAN message and service definitions (UAVCAN v0 DSDL)
firmware/
  lib/beam.[ch]       beam steering: per-element phase codes for an az/el direction
  test/               host unit tests (make -C firmware test)
hardware/
  README.md           stack-up and board partitioning proposal
  element_positions.csv  patch centres, generated by tools/array_calc.py
tools/
  array_calc.py       geometry, patch size, beamwidths, sidelobes
  radar_budget.py     waveform and detection-range estimates
  validate_dsdl.py    parses the DSDL with the DroneCAN parser
```

## Quick start

```sh
pip install -r tools/requirements.txt
python3 tools/array_calc.py        # array figures
python3 tools/radar_budget.py      # waveform and range estimates
python3 tools/validate_dsdl.py     # check the DroneCAN definitions
make -C firmware test              # beam-steering unit tests
```
